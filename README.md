# Kteccai Word Writer

Official downloads and update feed for the standalone Kteccai Word Writer.

Choose the latest release for Windows 10/11 x64, Mac Apple Silicon (arm64), or Mac Intel (x64). Writer 1.5.0 and later check this repository for updates. Install the latest release manually once to enable checking. Mac downloads require manual replacement; packages are not Apple Developer ID signed or notarized.
